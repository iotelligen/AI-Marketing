# Facebook Content Skill

## Objective
Make Industrial IoT understandable and relevant to factory owners.

## Writing Guidelines
- Use accessible language.
- Start with a relatable industrial problem.
- Keep paragraphs short.
- Explain technical solutions simply.
- Use practical examples from factories in Bangladesh.
- Encourage comments and discussion.
- Include a clear call to action.

Avoid overly technical language unless the topic requires it.
