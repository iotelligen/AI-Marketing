# TikTok Content Skill

## Objective
Create short-form videos explaining industrial problems and solutions.

## Required Output
- Video hook
- Script
- Scene descriptions
- On-screen text
- Caption
- Hashtags

## Writing Guidelines
- Capture attention in the first 3 seconds.
- Focus on one problem or idea.
- Use simple spoken language.
- Keep the script concise.
- Show practical industrial applications.
- End with a clear message or call to action.

Avoid unnecessary introductions.
