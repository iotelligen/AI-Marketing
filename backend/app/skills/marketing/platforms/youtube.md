# YouTube Content Skill

## Objective
Create educational and promotional video content about Industrial IoT.

## Required Output
- Video title
- Description
- Video script
- Suggested scenes
- Thumbnail concept
- Relevant keywords

## Script Structure
1. Opening hook
2. Industrial problem
3. Explanation
4. Solution
5. Practical example
6. Conclusion and call to action

Use technically accurate explanations and a natural speaking style.
